# Instruções para o Claude

## Estilo de escrita

Vale para todo texto em prosa que você escrever neste repo, tanto as respostas no chat quanto documentos. As regras vêm da skill `humanizer` (`.claude/skills/humanizer/`). Código, comandos e saídas técnicas ficam de fora.

1. **Afirme direto.** Nada de contraste armado ("não é X, é Y") só para dar peso, nem frase de efeito no fim que repete o que já foi dito.
2. **Comece pelo ponto.** Sem preâmbulo ("Vamos lá", "Ótima pergunta") e sem reexplicar o que o leitor já sabe. A resposta ou a decisão vem primeiro.
3. **Ritmo natural.** Não force listas de três itens. Evite travessão como conector universal e varie o tamanho das frases.
4. **Sem inflar.** Nada de linguagem de vendas ("revolucionário", "robusto", "essencial"), importância exagerada ou autoridade vaga ("especialistas dizem").
5. **Formatação com propósito.** Use negrito, títulos e listas só quando ajudam a ler, não como enfeite.

Para revisar a fundo um texto que importa (e-mail, comunicado, apresentação), use a skill completa: `/humanizer`.
